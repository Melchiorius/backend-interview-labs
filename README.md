# Backend Interview Labs

Практическая лаборатория для системной подготовки к техническим собеседованиям Java Backend уровня Middle+/Senior.

Репозиторий объединяет:
- связные конспекты теории с объяснением внутренних механизмов;
- небольшие, самостоятельно запускаемые примеры на Java;
- тесты, демонстрирующие гарантии и граничные случаи;
- практические лабораторные задания;
- материалы по System Design и принятию архитектурных решений.

## Принципы подготовки

1. Сначала понять механизм, затем запоминать формулировки.
2. Каждый важный тезис подкреплять примером или контрпримером.
3. Различать гарантии языка, JVM, библиотеки и конкретной реализации.
4. Разбирать не только правильный сценарий, но и гонки, отказы, таймауты, отмену и деградацию.
5. Не ограничиваться ответом «что это»: объяснять, зачем механизм нужен, как работает и чем приходится платить за его использование.
6. Практические задания усложнять постепенно. Самостоятельное написание кода с нуля не является обязательным первым этапом.

## Структура

- docs/ — план подготовки, методика, шаблоны и прогресс.
- labs/concurrency/ — потоки, синхронизация, Java Memory Model и блокировки.
- labs/collections/ — коллекции, хеширование и конкурентные структуры данных.
- labs/jvm/ — память, загрузка классов, JIT и сборка мусора.
- labs/async/ — Executor, Future, CompletableFuture, отмена и обработка ошибок.
- System Design — отдельный теоретико-практический трек в плане подготовки.

## Технологическая база

- Java 21 LTS.
- Maven, многомодульный reactor-проект.
- JUnit 5 для тестов.
- По умолчанию — чистая Java без Spring и инфраструктурных зависимостей. Фреймворки подключаются там, где они действительно нужны для изучаемой темы.

## Локальный запуск

Нужны JDK 21 и Maven 3.9+ (либо Maven, встроенный в IntelliJ IDEA).

Из корня репозитория — компиляция и все тесты:

```powershell
mvn clean verify
```

Тесты только лаборатории многопоточности (с нужными модулями):

```powershell
mvn -pl labs/concurrency -am test
```

В IntelliJ IDEA откройте корневой `pom.xml` как Maven-проект (или используйте File → Open и выберите корень проекта). Не импортируйте `build.gradle.kts`: Gradle больше не используется.

## Как работать с материалами

Начинайте с docs/ROADMAP.md и docs/STUDY_METHOD.md. Для нового раздела используйте docs/TOPIC_TEMPLATE.md. Текущий статус фиксируется в docs/PROGRESS.md.

Основной язык материалов — русский. Названия классов, методов, API и общепринятые технические термины сохраняются на английском.

## Статус

Создан каркас репозитория и многомодульная Maven-конфигурация. Добавлены первые две исполняемые лабораторные работы по многопоточности: потокобезопасный счётчик и ограниченная блокирующая очередь. Следующий этап — изучить и разобрать тесты и разбирать примеры вместе, после чего последовательно добавлять остальные темы.

## Безопасность и приватность

Не добавляйте в репозиторий пароли, токены, персональные данные, внутреннюю переписку работодателей или другие секреты. Перед публикацией материалов проверяйте, что они предназначены для открытого доступа.
