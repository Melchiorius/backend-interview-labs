# Collections Lab

Лаборатория по Java Collections Framework и структурам данных.

## Темы

1. Контракты Collection, List, Set, Map и Queue.
2. ArrayList и LinkedList: устройство и стоимость операций.
3. HashMap: хеширование, коллизии, resize и tree bins.
4. equals и hashCode: контракт и последствия нарушения.
5. ConcurrentHashMap: конкурентный доступ и атомарные операции.
6. Очереди, Deque и BlockingQueue.
7. Fail-fast и weakly consistent iterators.
8. Сложность операций и выбор структуры под нагрузку.

## Формат

Для каждой структуры данных рассматривать API-контракт, внутреннее устройство, сложность, ограничения, конкурентность и типичные ошибки использования.
