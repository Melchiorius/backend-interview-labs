Само по себе создание чата не выдаёт полномочий GitHub — для действий нужен доступ к соответствующим инструментам/репозиторию.

## Важный переходный период

Эти инструкции впервые публикуются в [PR #21](https://github.com/Melchiorius/backend-interview-labs/pull/21). **Пока PR не объединён**, нужные документы следует читать из ветки `ops/roles-and-workflow-20` (или страницы PR), а не считать их находящимися в `main`. После merge основная версия инструкций — `main`.

Перед действиями каждая роль **обязательно повторно проверяет актуальные GitHub `main`, Issue/PR и HEAD SHA**, вместо механического исполнения исторического «первого поручения», которое могло уже быть завершено.

Общие требования не копируются в эти файлы: первичны [AGENTS.md](../../AGENTS.md), [ROLE_MODEL.md](../ROLE_MODEL.md), [WORKFLOW.md](../WORKFLOW.md), [CURRICULUM.md](../CURRICULUM.md) и [COVERAGE.md](../COVERAGE.md). При конфликте роль должна зафиксировать разночтение и передать его 00/06, а не молча выбирать удобный стандарт.

Порядок создания чатов рекомендуется начать с **00 и 04** для проверки PR #21. После интеграции остальные роли могут начать работу над первой исследованной темой, не создавая параллельно несогласованные версии статей.
