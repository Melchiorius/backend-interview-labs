# Как пользоваться базой знаний без преподавателя

Это справка для читателя, **не обязательный учебный маршрут**.

1. Выберите статью в [каталоге](CURRICULUM.md) или по ссылке из другой статьи.
2. Сначала прочитайте определение, устройство, основную идею и короткий код/схему.
3. Если статья ссылается на другой термин, откройте его и вернитесь назад. Необязательные уточнения можно пропустить.
4. Если есть крупный пример — откройте файл Java. Если есть задание — измените заготовку и выполните указанные в README **тесты именно этой задачи**.
5. Вернитесь к объяснению, посмотрите альтернативы или перейдите к другой теме. Рекомендации для повторных проходов — [ROADMAP](ROADMAP.md).

Доступ к автору, преподавателю или ИИ не требуется. Наличие статьи **не подразумевает** обязательной задачи. Короткий демонстрационный код намеренно остаётся внутри Markdown.

Для авторов: редакционные требования находятся в [AGENTS.md](../AGENTS.md), технический стандарт задач — в [EXERCISE_AND_TESTING_STANDARD.md](EXERCISE_AND_TESTING_STANDARD.md).
