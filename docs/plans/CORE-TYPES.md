# CORE-TYPES — исследовательский план и проверка покрытия

**Дата:** 2026-11-19. **Цель:** статья о переменных, типах и значениях, не переписывающая все главы JLS. **Исследование до текста:** [общий аудит](../JAVA_CORE_COVERAGE_AUDIT_2026-11-19.md), [реестр источников](../SOURCE_REGISTRY.md), JLS 21 §§3.10, 4.2, 4.3, 4.12, 14.4, 16; [teamlead/java-interview-questions](https://github.com/teamlead/java-interview-questions) (типы, final, области памяти), [Baeldung Java Interview Questions](https://www.baeldung.com/java-interview-questions) (примитивы/ссылки/стек-куча/параметры). Внешние подборки использованы для выбора вопросов, но не для нормативных утверждений.

**Границы:** полный ожидаемый минимум по переменной, типу, ссылке, примитивам, литералам, `var`, `final`, инициализации, `null` и `==`. НЕ включать сюда формальные правила выбора перегрузки, алгоритмы GC, полную Unicode-обработку, коллекции или `equals/hashCode`.

**Контрпримеры:** `long x = 2147483648;`, `float f = 1.5;`, `var x = null;`, `int local;` перед чтением, `final` ссылка с изменяемым объектом; целочисленное переполнение и UTF-16 проверяются в [запускаемом примере](../../examples/core/TypesAndVariablesDemo.java). Некомпилируемые примеры оставлены комментариями в статье, чтобы не ломать CI.

**Coverage gate:** P0-пункты имеют локальный ответ и ограничение; P1/P2 явно направлены в другие темы (если файла нет — текстовый ID, не битая ссылка). Файл примера проверен локально на OpenJDK 21.0.12.1; PR CI также запускает `java examples/core/TypesAndVariablesDemo.java`. Проверка визуальной навигации в Obsidian остаётся непроведённой.

**Нужны новые исследования при расширении:** JLS §15.7 (порядок вычислений), §5 (сложные преобразования), более широкий банк реальных интервью-вопросов по JVM-memory; в данной статье они не объявлены покрытыми.
