# Состояние разработки репозитория (историческая сводка)

**Дата исходной сверки: 2026-11-19.** Фактический статус каждого учебного направления и дальнейшие дополнения учитывать в [COVERAGE.md](COVERAGE.md). Здесь **не хранится личный прогресс читателя**.

На исходной базе `main`: Java 21, Gradle multi-project с `labs/concurrency`, `labs/collections`, `labs/jvm`, `labs/async`; известны `SynchronizedCounter`, `BoundedBlockingQueue` и JUnit-тесты. Доступность Gradle Wrapper и прошлые успешные проверки зафиксированы в истории проекта; эти сведения не доказывают работоспособность будущих упражнений.

В документационном PR #5 разработаны инструкции и карта знаний. **Новые `knowledge/`, `exercises/`, `.run/`, интеграция Mockito и изолированные задачи на момент сверки ещё не были созданы.** Текущая ветка не является свидетельством появления этих файлов в `main`.

Отдельный PR #4 предлагал Maven вместо Gradle; на момент исходной сверки он оставался открытым. Принятую систему сборки следует проверять по актуальному `main`, а не делать вывод из этой исторической заметки.
